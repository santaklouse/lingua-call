# LinguaCall (рабочее имя)

P2P-видеосвязь с автоматическим переводом речи в субтитры — без сторонних
платных сервисов и без серверов: всё работает в браузере.

- **Транспорт:** [`go-p2p-netcat`](https://github.com/santaklouse/go-p2p-netcat)
  (libp2p + native WebRTC, pairing-токены `pnc1_`).
- **Медиа:** WebCodecs (VP8/VP9/H.264 + Opus) поверх аутентифицированного
  data channel.
- **Речь:** WASM-модели в браузере (streaming-ASR sherpa-onnx/Vosk + MT
  Bergamot), приватно и бесплатно.
- **Дубляж:** пользователь слышит переведённую речь (sherpa-onnx WASM VITS,
  piper-голоса ru/en; fallback — голоса ОС), оригинал приглушается через
  WebAudio. Это главная фича, а не только субтитры.
- **Выбранный вариант:** A — «всё в браузере» (решение 2026-11-07).

## Быстрый старт

Требования: **Bun ≥ 1.2** (рантайм, пакетный менеджер и тест-раннер).
Go ≥ 1.25 — опционально (для сборки `p2p-nc` и тестов совместимости).

```bash
bun scripts/check-prereq.mjs
bun install
bun run dev       # UI на http://localhost:5173
bun run typecheck
bun run lint
bun test
bun run build
```

## Статус

Bootstrap P0 завершён (12/12), тулинг — Bun. UI уже содержит выбор языка, lobby
с созданием/подключением чата (мок-токены) и временный экран простого
WebRTC-звонка (SDP-коды копированием). **Текущий фокус (D19) — пайплайн
перевода и озвучки**: микрофон → VAD → ASR → MT → субтитры + озвученный перевод
с метриками задержек. Транспорт `go-p2p-netcat` и локальные WASM-движки
отложены (см. `PLAN.md`).
